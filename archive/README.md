# Резервные выгрузки корпуса

Снимаются `scripts/backup_corpus.py` — читает сервис по API и складывает
каждый источник отдельным `jsonl.gz`. Политика целиком — в `docs/backup.md`.

## `service-only/`

Тридцать один источник австрийского корпуса, заведённый ДО нынешнего
пайплайна: каталога в `books/` у них нет, профиля нет, PDF в контейнере не
сохранились. До этой выгрузки они существовали в единственном экземпляре —
в базе на машине сервиса.

31 912 чанков, 17 МБ. Строка файла — чанк ровно в том виде, в каком его
отдаёт `GET /sources/{id}/chunks`: `external_id`, `citation`,
`point_number`, `text`, `hierarchy`, `page_start`/`page_end`,
`universal_ref`.

Чего здесь нет:

* **Эмбеддингов** — API их не отдаёт. Пересчитываются из текста
  (`text-embedding-3-small`, весь корпус меньше доллара).
* **Сносок** — на момент выгрузки сервис работал на коде без
  `?with_footnotes=true`. Сноски у этих источников ЕСТЬ (в выборке из трёх
  чанков попадалось до сорока шести), и выгрузку надо повторить сразу после
  развёртывания: `python3 scripts/backup_corpus.py --with-footnotes yes`.

Карточек тридцати восьми книг здесь нет намеренно: они лежат в
`books/*/output/cards.jsonl.gz` и воспроизводимы из PDF и профиля.
