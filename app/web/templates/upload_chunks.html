Загрузить чанки

JSON-файл с уже нарезанными фрагментами и посчитанными эмбеддингами — результат работы внешнего скрипта нормализации PDF. Сайт эмбеддинги не считает, только сохраняет присланные.

Если в чанках указан external_id (стабильный id из скрипта нарезки) — повторная загрузка того же файла для этого источника обновит существующие чанки, а не задублирует их. Без external_id каждая загрузка добавляет новые строки.

Ожидаемый формат файла

Объект с массивом chunks — та же схема, что у POST /sources/{id}/chunks:

{
  "chunks": [
    {
      "external_id": "terre-obligations-13ed-p1-n19",
      "citation": "Terré et al., Les obligations, 13e éd., n° 19",
      "point_number": "19",
      "text": "Le contrat est un accord de volontés…",
      "hierarchy": ["Livre 1", "Titre 1", "Chapitre préliminaire"],
      "page_start": 42,
      "page_end": 43,
      "printed_page_start": 26,
      "printed_page_end": 27,
      "embedding": [0.0123, -0.0456, "… 1536 чисел всего"],
      "concept_ids": [],
      "footnotes": [
        {"number": 1, "text": "V. Cass. civ. 1re, 3 juin 2010."}
      ]
    }
  ]
}

page_start/page_end — страницы ФАЙЛА-источника, printed_page_* — страницы печатного издания. Наружу показываются только вторые: первые в чужой сноске дадут не ту страницу. Если типографской пагинации в файле нет, printed_page_* опускаются.

Полная схема — на /docs (модель ChunkCreate).
