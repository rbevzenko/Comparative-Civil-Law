# Правки скилла complaw-corpus

Здесь лежит не сам скилл, а его изменённые файлы. Скилл синхронизируется из
claude.ai в `~/.claude/skills/synced/complaw-corpus/`, и правка на месте
переживает сессию, но не переживает следующую синхронизацию — поэтому копия
хранится в репозитории книг, рядом с корпусами, которые её и породили.

Чтобы правки не потерялись, эти файлы надо положить в скилл на claude.ai:

| Файл | Что изменилось |
|---|---|
| `SKILL.md` | Раздел про тома больше полутора тысяч страниц в шаге «Ветка»; ссылка на новый справочник |
| `references/large-volumes.md` | Новый. Тома в несколько тысяч страниц целиком |
| `references/profile-format.md` | Когда `margin.scope: book` обязателен; оглавление раздела в `junk.patterns`; знак сноски как конвенция издательства |
| `references/qa-and-regression.md` | Метрика, посчитанная не по тем полям; три сигнала, с которых смотреть большой том |

Написано по разбору Koller/Lovrek/Spitzer, Insolvenzordnung² (3727 страниц,
8774 карточки) и Koziol – Welser/Kletečka, Grundriss I (709 страниц, скан).
Оба корпуса лежат в `books/`, там же профили изданий и журналы решений.
